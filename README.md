# 📊 Pesquisa de Opinião - TudoWeb
Programa em Python para realizar uma pesquisa de satisfação sobre o atendimento da empresa ficticia TudoWeb.

## 🎯 Objetivo
Coletar os dados de 50 entrevistados:
* Nome
* Idade
* Opinião sobre o atendimento

### Opções
* ⭐ 1 - EXCELENTE
* 👍 2 - BOM
* 👎 3 - RUIM

Ao final, são exibidas as quantidades de respostas EXCELENTE, BOM e RUIM.
